BIBLE365 SUPPORT

每天一點，按自己的步調讀聖經。

Bible365 提供一年讀經計畫、離線聖經閱讀與本機經文收藏。這裡整理常用操作；若遇到問題，歡迎透過電子郵件聯絡。

每日讀經：切換日期與閱讀進度

開啟「每日讀經」，點選詩篇、新約、舊約或箴言區域，展開當天經文。使用前一天、後一天或今日按鈕切換日期，也可點選日期區域開啟日曆，直接選擇想閱讀的日期。

一年讀經計畫將 2 月 29 日安排為休息日，這一天沒有閱讀經文是正常設計。

聖經閱讀：搜尋、選取與複製

在「聖經閱讀」選擇書卷與章節，或輸入關鍵字搜尋經文。每章最下方提供上一章與下一章，方便接續閱讀。

點選經文可選取整節，再按複製或收藏；按重設可一次取消目前的選取。複製內容包含章節出處與經文正文。長按文字的選取方式會依裝置與作業系統有所不同。

收藏與 JSON 備份

收藏保存在手機內，可搜尋、複製或刪除；每頁顯示 20 筆，使用上一頁與下一頁瀏覽。點選收藏的經文，可直接開啟對應閱讀位置。

在「設定」中匯出收藏，即可透過系統分享介面儲存 JSON 備份；匯入先前的 JSON 檔可合併收藏，重複項目會略過。這不是自動雲端同步，請自行保管備份檔。

更換手機或解除安裝前，建議先匯出備份，並確認檔案保存在 App 以外的位置。請勿在公開問題回報中上傳不想公開的收藏備份。

語言、字體與佈景

在「設定」調整字體大小與明亮、深色佈景。介面支援繁體中文、簡體中文、英文及日文，切換語言時也會切換對應經文。

  • 繁體中文：和合本。
  • 簡體中文：和合本簡體字形轉換版。
  • 英文：King James Version（KJV）。
  • 日文：口語訳聖書，新約 1954 年／舊約 1955 年原版。

內建經文及主要閱讀、搜尋、收藏功能皆可離線使用。寄送支援郵件及開啟本網站則需要網路。
